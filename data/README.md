# Datos — NO versionados

Los archivos de datos **no se suben a git** (`.gitignore`).

## Cómo obtenerlos

1. Entra a la competencia: https://www.kaggle.com/competitions/titanic/data
2. Acepta las reglas de la competencia (botón "Join Competition")
3. Descarga y coloca aquí:
   - `train.csv` — 891 pasajeros con etiqueta `Survived`
   - `test.csv` — 418 pasajeros sin etiqueta (para la submission)
   - `gender_submission.csv` — ejemplo del formato de entrega
